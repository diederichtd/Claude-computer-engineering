# Changelog

## 1.0.0 (2026-09-27)

First release.

- Core method: state assumptions, show the formula with units, sanity-check every result
- Checklist of 22 common computer engineering traps
- Teaching mode for students and design-review mode for real projects
- Reference guides: digital logic and HDL, computer architecture, low-level programming, embedded systems, operating systems, networking, circuits and electronics
- Templates: design review checklist, debug log, lab report, formula sheet, HDL module and testbench templates
- `cecalc.py` with 14 calculators: number conversion, IEEE 754, cache geometry and trace simulation, AMAT, CPU time, Amdahl, virtual memory, subnets, MCU timers, UART baud, ADC, RC, Hamming, CRC
- Claude Code plugin and marketplace manifests
- Combined documentation in `docs/` (Markdown, HTML, PDF) and `tools/build_docs.py` to rebuild it
- `CLAUDE.md` with contributor instructions for Claude Code
